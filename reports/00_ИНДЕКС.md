# 🧬 Генетический профиль — индекс для ассистента жизни

**Источник:** файл `4wngq9.vcf` (Genotek, hg19, chip ~632K SNP)
**Дата анализа:** 26 июля 2026
**Покрытие:** проверено 193 ключевых rsID, найдено в файле 86 (45%)

## ⚠️ Как читать эти файлы

1. **Это НЕ медицинский диагноз.** Это генетическая предрасположенность по конкретным точкам. Реальное здоровье = генетика + среда + образ жизни.
2. **Файл chip, не WGS** — покрыты только заранее выбранные точки. Многие гены проверены частично или отсутствуют.
3. **Генотипы:** `0|0` = норма, `0|1` = носитель (от одного родителя), `1|1` = гомозигота (от обоих), `./.` = нет данных.
4. **Канонические интерпретации** сверены с dbSNP/PharmGKB; где GLM-5.2 давала противоречия, взят канонический вариант.

## 💊 Препараты для медкарты (RED FLAGS)
- 🔴 **Клопидогрел (Плавикс)** — неэффективен → прасугрел/тикагрелор
- 🔴 **Симвастатин ≥40мг** — риск миопатии → розувастатин в низкой дозе
- 🔴 **Варфарин** — нужна сниженная доза (VKORC1)
- 🟡 **НПВС** — снизить дозу на 20-40% (CYP2C9)
- 🟡 **Азатиоприн** — 30-80% стандартной дозы (TPMT)
- 🔴 **Перед химиотерапией**: проверить DPYD
- 🔴 **Перед антималярийными/сульфаниламидами**: проверить G6PD
