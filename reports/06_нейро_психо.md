# 🧠 Нейро и психология

> Источник: `4wngq9.vcf`. COMT/BDNF — психогенетика; APOE — риск Альцгеймера.

## ✅ Сильные стороны (норма по основным маркерам)

### rs4680 — COMT Val158Met (Warrior/Worrier)
- **Ваш генотип:** `0|0` (G/G) = **Val/Val = Warrior**
- **Что значит:** Быстрый распад дофамина в префронтальной коре. Вы лучше работаете **под стрессом** (дофамин не зашкаливает), но в покое — чуть хуже креативность/память.
- **Практически:**
  - Стрессоустойчивость — ваша сильная сторона
  - Хорошо справляетесь с давлением, дедлайнами, кризисами
  - Кофеин умеренно полезен (повышает дофамин в коре)
  - Для фокусировки в спокойной обстановке — физическая активность, ритмичность

### rs6265 — BDNF Val66Met
- **Ваш генотип:** `0|0` (C/C) = **Val/Val**
- **Что значит:** Нормальная выработка BDNF (нейротрофический фактор мозга). Хорошая нейропластичность — мозг эффективно учится и адаптируется.
- **Практически:** Аэробные нагрузки дополнительно повышают BDNF — используйте для обучения/памяти.

### rs7412 + rs157582 — APOE (Альцгеймер)
- **Ваш генотип:** rs7412 `0|0`, rs157582 `0|0`
- **Что значит:** Нет ε4-аллеля APOE. **Базовый популяционный риск** Альцгеймера (не повышенный).
- ⚠️ rs429358 (вторая позиция для полного APOE-типирования) — **отсутствует в файле**. Полный статус APOE (ε2/ε3/ε4) по rs7412+rs429358 установить нельзя. Но по rs7412 = норма.

## ⚠️ Зона внимания (GWAS-маркер, малый эффект)

### rs9271366 — HLA-локус (6p21.2)
- **Ваш генотип:** `1|1` (гомозигота)
- **Что значит:** GWAS-исследования связывают с **незначительным** повышением предрасположенности к расстройствам аутистического спектра (РАС) в популяции.
- ⚠️ **Очень важно:** это статистический маркер с **малым эффектом** (OR ≈ 1.1-1.3). Реальный риск определяется сотнями локусов + средой. Сам по себе этот генотип **не диагноз** и ничего не значит клинически без других данных.

## 📋 Резюме для ассистента

**Психогенетический профиль — благоприятный:**
- COMT Warrior — стрессоустойчивость, хорошо под давлением
- BDNF Val/Val — хорошая обучаемость, нейропластичность
- HTR2A сбалансирован — нормальная серотониновая система
- APOE (по доступной половине) — без ε4-риска Альцгеймера

**Стратегия для мозга:** аэробные нагрузки (повышают BDNF), умеренный кофеин (помогает фокусу у COMT Val/Val), регулярный сон.
